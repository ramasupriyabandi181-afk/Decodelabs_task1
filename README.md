Rule-Based AI Chatbot 🤖

Project Overview

This project is a simple Rule-Based AI Chatbot developed using Python as part of Project 1 of the DecodeLabs Artificial Intelligence Industrial Training Kit.

The chatbot interacts with users by providing predefined responses based on their inputs using "if-elif-else" statements and a continuous loop.

Objectives

- Handle greetings such as Hi, Hello, and Hey.
- Respond to predefined user questions.
- Use conditional statements for decision-making.
- Run continuously until the user enters an exit command.

Technologies Used

- Programming Language: Python
- Concepts: Conditional Statements, Loops, String Handling, User Input

Features

- Greeting responses
- Predefined question-and-answer responses
- Case-insensitive input handling
- Continuous conversation
- Exit commands such as "bye", "exit", and "quit"
- Default response for unknown inputs

How to Run the Project

1. Install Python 3 if it is not already installed.
2. Download or clone this repository.
3. Open the project folder in VS Code or a terminal.
4. Run the following command:

python chatbot.py

On Windows, you can also use:

py chatbot.py

Example Interaction
